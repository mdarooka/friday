# Google Places enrichment

Friday can use Google Places API (New) to look up a named place and return a verified address, official site, rating, review count, opening-hour descriptions, a small selection of review text, and current photo URLs with contributor attribution. Lookups happen on demand from an authenticated app request; the result is not written into trip or place records by this provider module.

Enable Places API (New) in Google Cloud, create a server-only API key, and set `GOOGLE_PLACES_API_KEY`. Restrict that key to Places API (New) and the Friday server's IP/network where possible. The API key is sent only in the server-to-Google request header. The browser receives same-origin, short-lived photo proxy URLs; the server asks Google's fixed Place Photos endpoint for the image URI and redirects only to HTTPS `googleusercontent.com` hosts.

The app forwards authenticated `GET /api/place-details?q=...` searches and `GET /api/place-details/:placeId` lookups to `createGooglePlacesIntegration({apiKey, fetch})` in `server/places.mjs`. Photo links use `GET /api/place-photo/:placeId/:photoRef?expires=...&sig=...`; the signature binds the photo resource to a short expiry, and the server rejects modified references. Keep these URLs transient: Google says photo resource names can expire and must be obtained again from a current Place Details or Text Search response.

The module requests an explicit field mask for place identity, display name, formatted address, location, website, Google Maps link, regular opening hours, rating, review count, reviews and photos. The `provider` and `attribution` response fields identify Google Places/Google Maps; photo and review author details are preserved for the UI. Google requires the relevant author attributions to be displayed, and Places data shown on a map has separate Google Map display requirements. Review Google's [Places API policies](https://developers.google.com/maps/documentation/places/web-service/policies), [Text Search (New)](https://developers.google.com/maps/documentation/places/web-service/text-search), [Place Details (New)](https://developers.google.com/maps/documentation/places/web-service/place-details), and [Place Photos (New)](https://developers.google.com/maps/documentation/places/web-service/place-photos) before enabling the feature for users.

No API key is available in this workspace, so only mocked HTTP contracts are tested. The exact field mask includes premium place fields; review the current Google Maps Platform billing and terms for your project before enabling it.
